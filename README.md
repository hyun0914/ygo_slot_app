# Yu-Gi-Oh Slot (Flutter)

유희왕 카드 데이터를 기반으로 **카드를 랜덤으로 뽑는 과정을 슬롯(릴)처럼 연출**하고,
**오늘의 3칸 타겟(특정 카드 3장)** 과 결과가 맞으면 "적중"으로 판정해주는 Flutter 웹 앱입니다.
오늘의 타겟은 **하루 동안 고정**됩니다.

> 비공식 팬 프로젝트입니다. Konami 및 Yu-Gi-Oh!와 무관합니다.
> 카드 데이터/이미지 출처: YGOPRODeck API

## 주요 기능

### 🎲 랜덤 뽑기 (슬롯 릴 연출)
- 난이도: 도전(3장) / 기본(5장) / 편안(7장) — 뽑는 카드 수가 많을수록 잭팟 확률이 올라가는 위험도 선택
- 릴(슬롯) 애니메이션 + 단계별 정지 연출
- 결과 요약 팝업

### 🎯 오늘의 타겟 (데일리 슬롯 룰)
- 하루마다 시스템이 **특정 카드 3장**을 오늘의 타겟으로 고정 결정 (난이도별로도 하루 동안 고정)
- 한 번의 뽑기에서 3장을 모두 맞히면 잭팟
- 날 종류(**일반** / **보스**)는 타겟 구성과 무관하며, 연출(라벨·아이콘·색상, 보스 잭팟 발동 여부)에만 영향을 줌

### 🎰 잭팟 연출
- 타겟 3개 전부 적중 시 컨페티 + 스트릭 카운트
- **보스 잭팟**: 보스인 날 잭팟 달성 시 화면 3방향 컨페티, 풀스크린 골드 플래시, BOSS JACKPOT 오버레이, 골드 글로우 애니메이션

### 🎯 천장(피티) 시스템
- 잭팟 없이 흘러간 뽑기 횟수(`missCount`)를 추적하는 천장 포인트 시스템
- **소프트 천장(200)**: 200회부터 부족한 타겟 카드를 보너스로 끼워 넣어줄 확률이 점차 상승
- **하드 천장(500)**: 500회 도달 시 부족한 타겟을 모두 채워 넣어 확정 잭팟
- 잭팟 달성 시 0으로 리셋, 타겟이 바뀌는 날에도 리셋 (누적 달성 횟수는 유지)
- 상단 천장 칩으로 현재 진행도 확인 가능 (소프트 천장 근접 시 골드로 강조)

### ⚔️ 잭팟 배틀 (보상 미니게임)
- 잭팟(타겟 3장 적중) 달성 시 자동으로 발동하는 3라운드 배틀 미니게임
- 오늘의 타겟 3장이 보유 카드를 대표해 상대 카드와 ATK/DEF 랜덤 모드로 자동 대결
- 동점 시 수비력 → 3판 2승(동전 던지기) → 스펠/함정의 스펠 스피드 등급 순으로 승부 결정
- 승수에 따라 보상 카드 지급(3승 → 3장 / 2승 → 2장 / 1승 → 1장 / 0승 → 위안 카드 1장)
- **카드 도감(전리품)은 이 배틀의 보상 카드로만 채워짐** — 단순히 뽑는다고 도감이 늘어나지 않음

### 🎰 연속 뽑기 — 천장 포인트 베팅 미니게임
- 횟수 선택: 30 / 50 / 100 / 150 / 200 / 250 / 300 / 350회
- 횟수에 따라 천장 포인트를 베팅 (30·50회 → 1P, 100·150회 → 2P, 200·250회 → 3P, 300·350회 → 4P)
- 보유 천장 포인트가 베팅액보다 적으면 해당 횟수는 선택 불가
- 진행 중에는 일반 천장 증감이 적용되지 않고, 베팅 결과로 한 번에 정산
- **승리** (선택한 횟수 안에 잭팟이 한 번이라도 발생): 베팅액에 따라 보너스 카드 지급 후 포인트 0으로 리셋
  - 1P 승리 → 카드 1장, 2P 승리 → 카드 2장, 3P 승리 → 카드 3장
  - 4P 승리는 예외적으로 포인트를 리셋하지 않고 **2배로 적립** (카드 3장도 함께 지급)
- **패배** (선택한 횟수 안에 잭팟이 한 번도 없음): 천장 포인트가 베팅액만큼 차감 (0 미만으로는 내려가지 않음)
- 승리 시 보너스 카드는 데일리 카드 풀에서 무작위로 지급되며, 잭팟이 발생하면 잭팟 배틀 보상도 별도로 함께 받음
- 결과 요약 팝업에 적중 분포·잭팟률과 함께 베팅 성공/실패, 포인트 변화, 보너스 카드 획득 내역 표시

### 🧠 디코더 (카드 맞추기)
- 유희왕 Wordle 스타일 — 힌트를 보고 어떤 몬스터 카드인지 맞추는 미니게임
- **카드 진행**: 정답을 맞히면 즉시 다음 랜덤 카드로 전환 (개인별 독립 진행, 못 맞히면 카드 유지)
- **힌트 토큰**: 시작 3개, 하루 +1 (최대 5개), 카드 변경 후에도 글로벌 유지
- **무료 공개**: 카드마다 속성 1개 자동 공개 (토큰 소모 없음)
- **추측 제한**: 하루 3회, 자정 초기화 / 카드 전체 추측 이력 표시
- **자동 공개**: 추측 시 정답과 일치하는 속성은 힌트 패널에 자동으로 공개
- **판정**: 맞음(초록 ✓) / 틀림(빨강 ✗) — 전 속성 동일 기준 적용
- **카드 브라우저**: 종류 / 속성 / 레벨·랭크·링크 / 종족 드롭다운 필터 + 공격력·수비력 범위 입력 + 이름 검색
  - 레벨·랭크·링크 구분 표시 (레벨 4 / 랭크 4 / 링크 4 별도 필터)
  - 50개씩 페이지네이션
- **카드 풀**: YGOPRODeck 전체 몬스터 카드 (언어 필터 없음), 7일 로컬 캐시
- **힌트 항목**: 종류 / 속성 / 레벨(랭크/링크) / 종족 / 공격력 / 수비력

### 🔊 효과음 (Web Audio API)
- 오디오 파일 없이 Web Audio API 오실레이터로 합성
- 뽑기 시작 / 릴 틱 / 적중 / 잭팟 / 보스 잭팟 효과음
- 음소거 토글 지원

### 🏆 도전과제 (19종)
- 첫 뽑기, 첫 잭팟, 보스 잭팟, 연속 3/7/30일, 누적 뽑기 10/100/1000회 등
- 달성 시 상단 슬라이드 토스트 알림

### 📊 레벨 시스템 (15레벨)
- 뽑기/적중/잭팟 시 XP 획득
- 레벨업 시 풀스크린 애니메이션 연출
- AppBar에 현재 레벨 배지 표시

### 📚 카드 도감
- **잭팟 배틀 보상 카드** 또는 **연속 뽑기 베팅 승리 보너스 카드**로만 전리품(컬렉션)이 채워짐
- 수집 카드 그리드 열람, 검색 및 수집 통계

### 🔖 즐겨찾기
- 카드 상세 화면에서 즐겨찾기 토글
- 즐겨찾기 목록 페이지

### 🗓 주간 챌린지
- 매주 새로운 챌린지 (어둠 속성, 드래곤족, ATK 2000 이상 등 15종 로테이션)
- 진행률 원형 인디케이터 표시
- 모바일에서는 한 줄 요약으로 표시, 탭 시 상세 바텀시트 오픈

### 📅 스트릭 캘린더
- 최근 5주 플레이/잭팟 달성일 시각화

### 📈 통계 대시보드
- 총 뽑기/잭팟/스트릭/수집 카드/XP 한눈에 확인
- 히트 분포 차트, 최근 30일 플레이 현황

### ⚔️ 배틀 모드
- 뽑은 카드로 랜덤 풀 카드와 ATK 배틀
- 전적 기록

### 👤 계정 및 클라우드 동기화
- 이메일/비밀번호/닉네임으로 회원가입·로그인 (Firebase Auth)
- 로그인 시 Firestore에 게임 데이터 자동 동기화 (레벨·XP·도전과제·도감·스트릭 등)
- 뽑기 완료 시 자동 클라우드 저장
- 메뉴 → 클라우드 저장 / 로그아웃

### 🔔 웹 푸시 알림
- 오늘 아직 뽑지 않았을 때 리마인드 알림 (브라우저 권한 허용 필요)

## 기술 스택

| 패키지 | 용도 |
|---|---|
| `flutter` | UI 프레임워크 |
| `flutter_riverpod` | 전역 상태 관리 (XP·컬렉션·스트릭 등) |
| `http` | YGOPRODeck API 호출 |
| `shared_preferences` | 로컬 데이터 저장 (localStorage on web) |
| `confetti` | 잭팟/보스 잭팟 컨페티 연출 |
| `firebase_core` | Firebase 초기화 |
| `firebase_auth` | 이메일/비밀번호 인증 |
| `cloud_firestore` | 게임 데이터 클라우드 동기화 |
| `web` | AppNetworkImage 웹 환경 대응 |

> 효과음은 `dart:js_interop`으로 Web Audio API를 직접 바인딩해 오디오 파일 없이 합성합니다.

## 프로젝트 구조

```
lib/
├── core/
│   ├── api_client.dart               # YGO API 클라이언트
│   ├── models/ygopro_card.dart       # 카드 모델
│   ├── services/
│   │   ├── auth_service.dart         # Firebase Auth 래퍼
│   │   ├── cloud_sync_service.dart   # Firestore 동기화
│   │   ├── sound_service.dart        # 효과음 (Web Audio API)
│   │   ├── notification_service.dart # 웹 푸시 알림
│   │   └── share_service.dart        # 클립보드 공유
│   └── widgets/
│       ├── app_network_image.dart    # 네트워크 이미지 (웹 대응)
│       └── ygo_card_back.dart        # 카드 뒷면 UI
├── features/
│   ├── auth/presentation/pages/auth_page.dart        # 로그인/회원가입 UI
│   ├── random_draw/                                   # 핵심 뽑기 기능
│   ├── decoder/                                       # 디코더 (카드 맞추기)
│   │   ├── domain/decoder_card.dart                  # 카드 모델 + 종족·속성 한글 매핑
│   │   ├── domain/guess_result.dart                  # 추측 결과 판정
│   │   ├── application/decoder_store.dart            # 게임 상태 (Riverpod Notifier)
│   │   └── presentation/pages/decoder_page.dart      # UI (필터·카드목록·힌트패널·결과)
│   ├── achievements/                                  # 도전과제
│   ├── collection/                                    # 카드 도감
│   ├── favorites/                                     # 즐겨찾기
│   ├── level/                                         # 레벨/XP
│   ├── weekly_challenge/                              # 주간 챌린지
│   ├── stats/                                         # 통계 대시보드
│   └── battle/                                        # 배틀 모드
└── main.dart                                          # 앱 진입점 + AuthGate
```

## 주의 사항

- 비공식 팬 프로젝트입니다. Konami 및 Yu-Gi-Oh!와 어떤 형태로도 제휴/승인/후원을 받지 않습니다.
